The little field guide

Make a song, one stamp at a time.

Stamp Composer is a playful staff editor built around the M-VAVE FM-1’s own controls. The browser runs the same native application, with simulated controls and audio.

First minute: Start composing → Load Playground demo → Play song. Stop playback, choose another character, and press a note key to add your own part. ENV undoes a change.

Place, move, listen

ControlWhat it does
Note keysPlace and audition a note at the cursor, or at the playhead (nearest grid step) while the song plays. Multiple notes at the same position form a chord.
SELECTMove the time cursor one grid step.
PRESETSChoose a character and sound. The browser palette does the same thing.
ALGORITHMSelect an arrangement layer, 1–8.
PLAY / ARPStart or stop / toggle looping.
SEQCycle quarter, eighth, sixteenth, eighth-triplet and sixteenth-triplet grids.
OCT− / OCT+Shift the keyboard. Notes outside C2–C6 are refused. Both together toggle FREE PLAY: keys only sound, held notes last while the key is down, nothing is placed.

Shape your song

ControlWhat it does
K1 / K2 / K3 / K4Tempo / new-note velocity / new-note length / song end.
EDIT (tap)Step through the pages: staff, MIX, SOUND, MIDI, GROOVE, BARS, then back to the staff. GLO opens the song book.
Hold EDIT + a noteErase the matching pitch, sound and layer at the cursor. Holding to erase does not change pages. While playing it erases at the playhead.
Hold EDIT + K2 / K3Change the velocity / length of the selected sound’s notes at the cursor. One hold is one undo step.
Hold EDIT + PLAYPlay from the start of the cursor’s bar.
ENV / LFOUndo / redo, up to sixteen changes (stopped only).
RECDuplicate the current bar into the next bar.
FX / SELMute the selected sound / filter the staff to that sound.
HOMETap to return to the staff and the beginning of the song. Hold it for about half a second to see this page’s controls, then let go.

The other pages

PageK1 / K2 / K3 / K4
MIXBeats per bar (2–12) / sound volume / layer volume / song end. FX mutes and SEL solos the selected layer, even while playing; these are not saved.
SOUNDTune ±12 semitones / tone (dark to open) / decay (short to long) / pan left to right. Saved with the song.
MIDIThe sound’s channel (OFF, 1–16) / mode (OFF, ON, MIDI ONLY) / clock (OFF, OUT, IN). Notes go out per sound with velocity and length; clock IN follows an outside machine and the header shows EXT. Incoming MIDI notes act like keys.
GROOVESwing 0–75 (late off-beat eighths and sixteenths) / human 0–100 (a little random timing and loudness, the same every play).
BARSFrom bar / to bar / target bar / transpose ±12. REC copies, FX moves, SEQ deletes, ARP inserts empty bars, OCT+ transposes. SEL limits copy, move and transpose to the selected sound. A change that would not fit is refused whole, and each one can be undone.

On SOUND, MIDI, GROOVE and BARS the knobs turn only while the song is stopped. The time signature (MIX, K1) is the number of beats over 4, and bar lines follow it.

Swing and triplets: swing delays off-beat eighths and sixteenths. Notes on triplet positions are not swung, because triplets already carry the swung feel; SWING 33 moves an off-beat eighth onto the triplet position.

Keep something good

GLO opens the song book. K1 selects one of eight slots. SAVE writes your current song. Press REC twice to load the selected slot. Stop playback before saving, loading or changing settings. The song is also autosaved a few seconds after you stop touching things, and comes back (RESTORED) when the app starts again, in the same browser.

Browser saves use local storage. Clearing browser data removes them, so Export song makes a portable .scf copy. Import replaces the current song and can be undone with ENV. The demo also replaces the current song, with a second-click check when a song already has notes.

Keyboard & accessibility

White keys: Q–I and A–K. Black keys: 1–0 and minus. Z/X change octave; P plays and O duplicates the bar. Tab through every control; use arrow keys on knobs, Space or Enter on buttons. Drag a knob vertically with a mouse or touch. Shift-click latches a key or button.

The native app supplies screen-reader status for the current view. The simulator supports a system screen reader; it does not include a separate speech engine. All character buttons have sound names, keyboard focus and selected-state labels.

What this preview is

Fifteen recognizable character stamps, eight layers, a shared voice pool and 384 notes per song, between C2 and C6. Audio currently uses an original placeholder sample bank. This is a native-app simulation, not a PI32 firmware binary running in a CPU emulator. The firmware has not yet been tested on a physical FM-1; section chains and other ideas remain in development.
