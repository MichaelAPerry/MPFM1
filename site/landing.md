# Stamp Composer FM-1

**Little stamps. Big ideas.** A Mario Paint–inspired music composer for the M-VAVE FM-1. Version {{VERSION}}.

> **Development preview.** This firmware runs in an emulator but has not been tested on a physical FM-1 yet.

- [Try the firmware in your browser](fm1-emu/): the actual `{{PKG}}` package running in fm1-emu.
- [Quick preview](emu/): the same C source compiled to WebAssembly, with a clickable palette and song import/export.
- [Install](install/) with Chrome or Edge over USB, or download [{{PKG}}](firmware/{{PKG}}).
- [Source, controls and validation](https://github.com/MichaelAPerry/MPFM1).
